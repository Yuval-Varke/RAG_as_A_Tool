# RAG as a Tool

This project demonstrates a simple Retrieval-Augmented Generation (RAG) workflow using a Jupyter notebook. It includes a minimal environment setup and a runnable notebook that walks through the core steps of retrieving context and generating responses.

## Contents

- `RAGasATool.ipynb`: Main notebook with the end-to-end RAG flow.
- `requirements.txt`: Python dependencies.

## Getting started

1. Create and activate a virtual environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook and run the cells in order.
